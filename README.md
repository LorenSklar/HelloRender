# Project Title
Hello, Render!

## Description
This project is a Flask application that provides an API for greeting users in different languages using Google Translate.

## Features
- Greet users with a customizable name and language.
- Translate greetings to various languages using the Google Translate API.
- Error handling for invalid inputs and translation failures.

## Requirements
- Python 3.x
- Flask
- python-dotenv

## Setup
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd <project-directory>
   ```
# Start of Selection
3. Create a virtual environment:
   ```
   python -m venv venv
   ```
4. Activate the virtual environment:
   - On Windows:
     ```
     venv\Scripts\activate
     ```
   - On macOS and Linux:
     ```
     source venv/bin/activate
     ```
5. Install the required packages:
   ```
   pip install -r requirements.txt
   ```
6. Create a `.env` file in the root directory and add your Google Translate API key:
   ```
   GOOGLE_TRANSLATE_API_KEY=your_api_key_here
   ```
